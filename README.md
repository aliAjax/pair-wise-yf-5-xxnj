# 社区种子图书馆 · 借还页面

一个纯前端页面，直接用浏览器打开 `index.html` 即可使用（无需服务器）。
数据保存在浏览器 `localStorage`，关闭/重开页面后库存与借还记录仍在。

## 文件分块

| 文件 | 职责 |
| --- | --- |
| `js/data.js` | **目录数据块**：预置 6 个种子品种、3 名住户，以及状态的初始化/读取/保存/重置 |
| `js/library.js` | **借还判断块**：过期、缺货、周末交换课预留、当月 2 包上限、归还发芽判定等纯规则逻辑 |
| `js/app.js` | **页面入口块**：渲染概览/表单/归还列表/记录，处理按钮事件，规则全部调用 `SeedLibrary` |
| `index.html` / `styles.css` | 页面结构与样式 |

## 业务规则

- 每包种子有：库存（包）、采种年份、播种截止日。
- 借种时按以下顺序检查，任一不通过都说明原因且**数据保持原样**：
  1. 今天晚于播种截止日 → 已过播种期；
  2. 无可用库存 → 缺货，或库存已全部预留给周末交换课
     （库存 ≤ 4 包的品种先留 2 包，库存不足 2 包则全部预留）；
  3. 借用人当月已借 2 包 → 达到每人每月上限
     （按借出时间所在月份统计，含已归还/已失活的包）。
- 归还时先标记发芽情况：
  - 测试**仍可发芽**：库存 +1 回库，记录为「已归还」；
  - **已失活**：不回库，只登记为损耗。
- 首页展示每位住户当月借阅数/手中包数/剩余额度，以及各品种库存、采种年份、截止日与预留情况。
- 底部「恢复演示初始数据」可清空记录并还原预置库存。
